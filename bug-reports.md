# BUG-001: Login succeeds with an incorrect password

## Environment
- Browser: Google Chrome
- Testing Type: Manual Testing

## Preconditions
The login page is accessible.

## Steps to Reproduce
1. Open the login page.
2. Enter a valid username.
3. Enter an incorrect password.
4. Click the Login button.

## Expected Result
The application should reject the login attempt and display an appropriate error message.

## Actual Result
The application allows the user to log in despite the incorrect password.

## Severity
Critical — if unauthorized access is confirmed.

## Status
New — requires investigation.
