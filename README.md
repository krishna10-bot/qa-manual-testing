# QA Manual Testing Project

## About This Project
This is my beginner QA portfolio project. I manually tested a login page to practise software testing fundamentals, test case writing, and result documentation.

## Website Tested
https://practicetestautomation.com/practice-test-login/

## Testing Objectives
- Test login functionality.
- Verify behavior with valid and invalid credentials.
- Test empty input fields.
- Check password visibility.
- Observe error messages.
- Document test results.

## Testing Approach
I performed manual testing using different combinations of usernames and passwords. I compared the expected behavior with the actual results and recorded the status of each test case.

## Test Summary
